# Research boundary

This repository is a research and education workflow. It does not provide investment advice, promise returns, or connect to broker execution.

Published results must identify the data source, exact period, benchmark type, costs, point-in-time rules, parameters, missing-data behavior, known biases, and configuration hash. The CSI 300 comparison uses the price index unless a total-return series is explicitly supplied and labelled.

The historical figures in the original brief are reference claims. Never describe them as reproduced until the generated trade ledger and audit checks support the result.

The PandaData audit-opinion endpoint available for this run returned observations only from 2023 onward. The code does not accept `annual_report_available_proxy` as an audit opinion. Before true audit observations begin in 2023, the strict small-cap audit condition cannot be established from this cache, so those candidates are ineligible and the sleeve may remain in cash. Reports must state this coverage gap, and the run cannot be marked verified without a complete point-in-time audit history.
